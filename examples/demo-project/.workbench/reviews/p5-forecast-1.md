# p5-forecast 리뷰 1회차 — 통과 (pass)

가상의 요약입니다. 모든 수치는 가짜입니다.

## 결론
시간순 분할과 누수 점검을 통과했고 베이스라인보다 개선되었습니다. 외부 가정값은 승인 시 함께 확인해 주세요.

## 지적
- **assumptions (medium, 미해결)**: 전력 단가와 배출계수의 출처 확인이 남았습니다.
- **leakage (high, 해소)**: 미래 시점 집계값이 특징에 섞여 있어 제거했습니다.
- **documentation (low, 해소)**: 모델 카드에 학습 기간을 추가했습니다.

## 반대 증거 (3건)
- 개선폭은 겨울철 구간에서만 크고 나머지 구간에서는 작습니다.
- 구간 추정의 하한에서도 절감이 0보다 큽니다.
- 단가를 20% 바꿔도 시나리오 순위는 같습니다.
